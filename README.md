# 💧 Smart Water Quality Analyzer

## 📌 Overview
This project predicts whether water is safe for drinking using Machine Learning.

## 🚀 Features
- Takes water parameters as input
- Predicts Safe / Unsafe water
- Simple user interface using Streamlit

## 🛠️ Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit

## ▶️ How to Run

1. Install dependencies:
pip install -r requirements.txt

2. Train model:
python train.py

3. Run app:
streamlit run app.py

## 📊 Dataset
Water Potability Dataset from Kaggle

## 📈 Output
- Safe or Unsafe water prediction
