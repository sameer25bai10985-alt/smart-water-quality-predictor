# 💧 Smart Water Quality Analyzer & Safety Predictor

This project predicts whether water is safe to drink using Machine Learning.  
It takes parameters like pH, hardness, turbidity, etc., and classifies water as **Safe or Unsafe**.

---

## 📌 Problem Statement
Access to clean drinking water is a major issue. It is difficult to manually determine whether water is safe. This project solves this problem using Machine Learning.

---

## 🚀 Solution
A Machine Learning model is trained on water quality data to predict potability.  
A simple Streamlit web app allows users to input parameters and instantly check water safety.

---

## 🛠️ Technologies Used
- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- Streamlit  

---

## 📊 Features
- Predicts whether water is **Safe or Unsafe**
- Simple and interactive UI
- Real-time prediction using user input
- Provides suggestions based on result

---

## ⚙️ How It Works
1. Load dataset  
2. Handle missing values  
3. Split data into training and testing  
4. Train Machine Learning model  
5. Predict water quality  
6. Display result on UI
